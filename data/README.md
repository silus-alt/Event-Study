# Data

The data files are **not included** in this repository. They were obtained from the Taiwan Economic Journal (TEJ) database, whose license does not permit redistribution.

To reproduce the analysis, obtain the data through your own TEJ access and place the following files in this folder.

## Required Files

| File | Source | Used by | Description |
|---|---|---|---|
| `ols_data.xlsx` | TEJ | `01_ols_demo` | Daily stock and market returns for Foxconn (2317), event days -240 to +10 |
| `AR_tej.xlsx` | TEJ event study module | `02_data_cleaning` | AR and SAR for all 15 firms, event days -10 to +10 |
| `clean_event_data.csv` | Output of `02_data_cleaning` | `03`, `04`, `05` | Long-format AR and SAR |
| `firm_fund.xlsx` | TEJ + own calculation | `06_regression` | Firm characteristics and CAR by window |

## File Structure

**`ols_data.xlsx`** — one sheet, one row per trading day

| Column | Description |
|---|---|
| `Tau` | Event day relative to announcement (-240 to +10) |
| `Date` | Trading date |
| `Price` | Closing price |
| `Return` | Daily stock return (%) |
| `Excess_r` | Stock return minus market return (%) |
| `Market_r` | Daily market return (%) |

**`AR_tej.xlsx`** — two sheets in this order: AR, then SAR (wide format)

| Column | Description |
|---|---|
| `Tau` | Event day (-10 to +10) |
| One column per firm | AR (%) in sheet 1; SAR in sheet 2 |

Firm columns: `Shuttle`, `InterServ`, `Walsin`, `Teco (1)`, `SAA`, `UMC`, `Chipbond`, `TAC`, `ECPay`, `GMTC`, `Soft-World`, `Yao Sheng`, `JCP`, `Foxconn`, `Teco (2)`

**`clean_event_data.csv`** — generated by `02_data_cleaning`

| Column | Description |
|---|---|
| `Tau` | Event day |
| `firm` | Firm name |
| `AR` | Abnormal return (%) |
| `SAR` | Standardized abnormal return |

**`firm_fund.xlsx`** — one row per firm (15 rows)

| Column | Description |
|---|---|
| (first column) | Firm name |
| `LEAD` | 1 if leading firm, 0 if partnering firm |
| `TECH` | 1 if tech-oriented alliance, 0 otherwise |
| `RD` | R&D intensity |
| `BM` | Book-to-market ratio |
| `CAR -10~+10`, `CAR -5~+5`, `CAR -1~+1` | CAR (%) for each event window |
